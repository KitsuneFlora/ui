# 设计原则

我们给 `@kitsuneflora/ui` 定的视觉语言是「暖狐毛、舒适圆润」：温暖纸感、柔和圆角、琥珀品牌色；暗色模式也要站得住对比。

## 我们坚持的

1. **温暖表面** — 奶油纸与柔和棕色；暗色下我们会提亮品牌橙。
2. **圆润但不玩具化** — 圆角走 token；我们故意避开生硬的多边仪表盘硬边。
3. **Token 优先** — 组件里我们不写死色板，统一 `--fx-*`。
4. **命名空间** — 变量 `--fx-*`，类名 `fx-*`；我们不假设你的应用里有 `#app`。
5. **全局样式可选项** — `reset.css` / `preset.css` 必须你自己显式导入。
6. **默认可访问** — 可见焦点、可键盘 overlay、通用文案可本地化。
7. **预发布诚实** — `1.0` 前我们允许破坏性更新；不会做 deprecated alias、双写 token，或旧 `data-theme` 兼容。

## 定制边界

- 我们推荐你用 CSS 变量和已写进文档的 class / slot 来定制。
- 没写进文档的 DOM 结构，我们不保证稳定。
- 图表分类色、业务插画、产品导航不在我们库的范围内。
